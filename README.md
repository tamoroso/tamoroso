## Currently building

**Job Search Agent**: An AI-powered job discovery and matching system that automates job sourcing, evaluates CV–job fit, and delivers personalized job recommendations.

* **Data ingestion**: Automated scraping of job listings from ATS platforms
* **Database**: PostgreSQL with a structured, purpose-built relational schema
* **Matching**: Late-interaction retrieval inspired by ColBERT for fine-grained CV–job matching
* **Agentic layer**: Claude API for reasoning over matching results and generating personalized job digests
* **Backend**: Python, with modular architecture and separation of concerns
* **Engineering**: Automated testing, Docker, CI/CD, secure secrets management, and sensitive data anonymization

The goal is to go beyond keyword-based job search by combining fine-grained semantic matching with LLM-driven analysis. The system is designed around explicit data models, testable components, and maintainable architecture, with a focus on producing relevant, actionable results rather than generic AI-generated recommendations.
